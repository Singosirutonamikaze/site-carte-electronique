# CarteElectronique

## Description
CarteElectronique est un site web qui permet aux utilisateurs de créer une carte d'identité électronique avec leurs informations personnelles. Les utilisateurs peuvent entrer des données telles que le nom, le prénom, la date de naissance, le lieu de naissance et l'adresse. L'application génère également un code QR contenant ces informations pour un accès rapide.

## Fonctionnalités
- Formulaire de saisie des données personnelles
- Validation des entrées (nom, prénom, date de naissance, lieu de naissance, adresse)
- Affichage des informations saisies sur la carte
- Génération d'un code QR à partir des données saisies
- Réinitialisation du formulaire
- Téléchargement d'une photo
